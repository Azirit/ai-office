# Review Process

## Workflow

```
Задача
  ↓
Analyzer анализирует
  ↓
Executor реализует
  ↓
Reviewer проверяет
  ↓
Есть проблемы?
  ├─ Да → Executor исправляет → Reviewer повторно проверяет
  └─ Нет → Коммит
```

---

## Классификация проблем

### Blocker
Код нельзя принимать:
- Нарушает требование
- Ломает существующее
- Опечатка/баг

### Major
Серьёзная проблема:
- Сложная логика
- Дублирование
- Плохие имена

### Minor
Некритичная проблема:
- Мелочи
- Предпочтения

---

## Формат отчёта

```
## Result
Approved / Changes Requested

## Summary
Краткая оценка.

## Blockers
- Нет.

## Major
- Нет.

## Minor
- Нет.
```
