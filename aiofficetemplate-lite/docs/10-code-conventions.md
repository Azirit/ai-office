# Code Conventions

## Правила

1. Код должен быть понятен без объяснений.
2. Простое решение лучше сложного.
3. Не добавляй лишнего.
4. Не рефактори без необходимости.

---

## Именование

- Переменные: `camelCase`
- Компоненты: `PascalCase`
- Обработчики: `handle*`
- Boolean: `is*`, `has*`, `can*`

---

## Функции

- Одна функция — одна задача
- Ранний выход (early return)
- Мало параметров

---

## React

- Не мутируй state
- Не используй useEffect без необходимости
- Не создавай компонент ради 2 строк
- Соблюдай Rules of Hooks

---

## Когда разбивать

- Файл > 200 строк
- Функция делает 2 вещи
- Логика дублируется

## Когда НЕ разбивать

- Файл < 50 строк
- Всё понятно
- Разбиение добавляет файлов

---

## Исключения

Допускается нарушение правил, если:
- Повышает читаемость
- Есть техническая причина
- Правило конфликтует с задачей
