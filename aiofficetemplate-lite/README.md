# AI Office Template — Lite

## Быстрый старт

1. Скопируй `.opencode/` в корень проекта
2. Скопируй `docs/` в корень проекта
3. Готово

---

## Что это

Упрощённый шаблон для проектов без:
- Тестов
- Строгой архитектуры
- Лишних зависимостей

Для:
- Фич
- Баг-фиксов
- Простых проектов

---

## Агенты

### Orchestrator (Координатор)
- Распределяет задачи
- Координирует агентов
- Коммитит

### Analyzer (Аналитик)
- Анализирует код
- Находит проблему
- Документирует
- Не изменяет файлы

### Executor (Исполнитель)
- Пишет код
- Реализует требования
- Следует правилам
- Не коммитит

### Reviewer (Ревьюер)
- Проверяет код
- Ищет проблемы
- Классифицирует
- Не изменяет код

---

## Процесс

```
Задача → Analyzer → Executor → Reviewer → Коммит
```

---

## Правила кода

### JavaScript/TypeScript

- `camelCase` для переменных
- `PascalCase` для компонентов
- `handle*` для обработчиков
- Early return
- Не создавай абстракции без необходимости

### React

- Не мутируй state
- Не используй useEffect без необходимости
- Не создавай компонент ради 2 строк
- Соблюдай Rules of Hooks

### Когда разбивать

- Файл > 200 строк
- Функция делает 2 вещи
- Логика дублируется

### Когда НЕ разбивать

- Файл < 50 строк
- Всё понятно
- Разбиение добавляет файлов

## Git

### Ветки

```
feature/TASK-<номер>_<описание>
bugfix/TASK-<номер>_<описание>
refactor/TASK-<номер>_<описание>
```

### Коммиты

```
type(scope): description
```

Примеры:
```
feat(todo): add deletion
fix(todo): prevent empty
```

---

## Когда использовать

### Да
- Простые проекты
- Нет тестов
- Нет строгой архитектуры
- Быстрые фичи/баги
- **Реальная работа в проде**

### Нет
- Большие проекты
- Нужны тесты
- Нужна строгая архитектура
- Команда > 2 человек

## ВАЖНО: Git

**ВСЕ операции с Git ТОЛЬКО с явного подтверждения пользователя.**

Это продакшн-среда. Ошибки критичны.

### Агенты НЕ делают:
- `git add` (staging)
- `git commit`
- `git push`
- `git checkout` (создание веток)
- `git merge`
- Любые git-команды

### Агенты делают:
- Анализируют код
- Пишут код
- Ревьюят
- **Предлагают git-команды**

### Процесс:
1. Агенты делают свою работу
2. Orchestrатор предлагает git-команду
3. **Ты подтверждаешь**
4. Команда выполняется

### Пример:
```
Orchestrator: "Готово. Выполни: git add . && git commit -m 'feat(todo): add deletion'"
Ты: "Ок"
[выполняется]
```

Или:
```
Orchestrator: "Готово. Выполни: git add . && git commit -m 'feat(todo): add deletion'"
Ты: "Погоди, сначала проверь ещё раз"
[ждёт]
```
