# Чистая архитектура

## Принципы

1. **Зависимости направлены внутрь.** UI зависит от бизнес-логики, бизнес-логика от типов. Не наоборот.
2. **Изоляция бизнес-логики.** Бизнес-логика не зависит от фреймворка.
3. **Тестируемость.** Каждый слой можно тестировать изолированно.

---

## Слои

### UI Layer
- React компоненты (или другой UI фреймворк)
- Отвечает за отображение и ввод
- Содержит минимальную логику (валидация формы, форматирование)

### Business Layer
- Кастомные хуки (или сервисы)
- Управляет state
- Содержит правила бизнеса

### Data Layer
- API-вызовы, localStorage, база данных
- В текущей версии может отсутствовать

---

## Зависимости

```
UI Layer → Business Layer → Types
```

**Правило:** компоненты зависят от хуков, хуки зависят от типов.

---

## Границы

- **UI** не знает о бизнес-правилах
- **Business** не знает о DOM и React-компонентах
- **Types** не зависят ни от чего

---

## Исключения

Допускается нарушение принципов, если:
- Это повышает читаемость
- Существует объективная техническая причина
- Компонент < 50 строк и понятен без абстракций

Нарушение должно быть обосновано.
